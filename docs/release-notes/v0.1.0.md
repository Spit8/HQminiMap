title: HQminiMap 0.1.0 — première version

Première version publique de **HQminiMap** : une carte haute qualité et les données en direct de ta partie de Transport Fever 3, dans une application de bureau.

## Nouveautés
- **Orthomosaïque de la carte**
  - **GridLab** calcule la grille de capture (altitude, champ de vision de 10 à 66°, plus petite grille couvrante) et estime la taille de l'image avant la capture.
  - Le mod prend les captures vues du dessus dans le jeu.
  - **TileLab** les assemble en une image haute résolution.
- **Visualiseur** : zoom jusqu'au pixel, rotation, plein écran, export de la vue en PNG ×1, ×2 ou ×4 avec légende.
- **Données en direct** :
  - **villes** avec leur contour ;
  - **lignes** avec leur tracé réel ;
  - **gares et arrêts** aux couleurs de leurs lignes ;
  - **véhicules** animés, avec leur chargement ;
  - **industries** et **entrepôts**, avec leurs stocks ;
  - trafic et historique.
- **Filtres** :
  - par calque, nom, mode, trafic et stock, avec étiquettes et masquage ;
  - **configurations** enregistrables, importables et exportables.
- **Double-clic** sur la carte : la caméra du jeu s'y déplace.
- Interface en **français** et en **anglais**.

## Installation
**Application** : télécharge le fichier de ton système ci-dessous.

| Système | Fichier |
|---|---|
| Windows | `HQminiMap_0.1.0_x64-setup.exe` (ou le `.msi`) |
| Windows sans installation | `HQminiMap_0.1.0_x64-portable.zip` (décompresser, puis lancer `HQminiMap.exe`) |
| Linux | `.AppImage` (portable) ou `.deb` |
| macOS (Apple Silicon et Intel) | `.dmg` |

**Mod** :
1. Télécharge `hqminimap-mod-0.1.0.zip`.
2. Copie le dossier `hqminimap` dans `<Steam>/userdata/<SteamID>/3493540/local/mods/`.
3. Active **HQminiMap** dans les mods de ta partie.

Le mod n'est pas encore publié sur mod.io.

## À savoir
- L'app a besoin de **Microsoft WebView2**, déjà présent sur Windows 11 et la plupart des Windows 10.
  - Les installeurs l'ajoutent tout seuls s'il manque.
  - La version portable fournit `MicrosoftEdgeWebview2Setup.exe`, à lancer seulement si l'app ne démarre pas.
- Les installeurs **ne sont pas signés** : Windows SmartScreen (« Informations complémentaires » → « Exécuter quand même ») et macOS Gatekeeper (clic droit → « Ouvrir ») demandent une confirmation la première fois.
- Après une mise à jour du mod, **recharge ta sauvegarde**. L'app affiche un bandeau tant que le jeu exécute l'ancienne version.
- Les tracés des lignes se complètent au fil des passages des véhicules.

First public release of **HQminiMap**: a high-quality map of your Transport Fever 3 game and its live data, in a desktop app.

**Features**
- **Map orthomosaic**
  - GridLab plans the capture grid.

- **App**: download the installer for your system above (Windows `.exe` / `.msi` or the portable zip, Linux `.AppImage` / `.deb`, macOS `.dmg`).

  1. Download `hqminimap-mod-0.1.0.zip`.

  3. Enable HQminiMap in your game's mods.

**Good to know**
- WebView2 is installed automatically by the Windows installers if it is missing; the portable zip includes Microsoft's setup.
- The installers are not signed yet, so SmartScreen and Gatekeeper ask for a confirmation the first time.
- Reload your save after updating the mod.
