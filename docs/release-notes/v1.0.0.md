title: HQminiMap 1.0.0 — first public release

**HQminiMap** turns your Transport Fever 3 map into a sharp high-resolution orthophoto and shows your network on top of it, live: towns, lines, stations, vehicles, industries and warehouses.

## What's new since 0.2.0
- **Six languages**: English, French, German, Italian, Spanish and Simplified Chinese, in the app and in the game window. The in-game window follows the game's language.
- **One-click scan from the app**
  - GridLab and TileLab are now a single **GridLab** tab.
  - Choose a **capture mode** (Simple, x4, x16 or x64 images). GridLab sets the grid, camera and lighting for your map and your resolution.
  - **Scan the map in game** starts the scan in your running game; you no longer need to open the mod window.
  - When the scan ends, the orthophoto is **built by itself** and opens in the Viewer.
- **More reliable scans**: screenshots matched by the game's own counter, steady pace of 1.25 s per image, works at any frame rate, scans no longer restart on their own.
- **Relief**: altitude colours, contour lines or both, with your own colour scale and balance.
- **Plain basemap**: black background, blue water with smooth shores and the map outline, to make your lines stand out.
- **Lines**
  - One lane per direction in streets, striped when several lines share it.
  - Continuous tracks, without breaks at bends and junctions.
  - A single averaged track per ferry or flight route.
  - The selected line is drawn above everything else.
- **Vehicles**: framed load badges (passengers and cargo).
- **Options → Map**: line width.
- **Viewer**
  - Lighter toolbar and floating tool bubbles that fade away.
  - Image settings remembered per orthophoto.
  - Resizable side panels.
- **Performance**
  - The map only redraws what changed and pauses while hidden.
  - A performance monitor simplifies the display on very large networks.
- **Automatic app updates**: from this version on, the app updates itself from the GitHub releases (installers and AppImage).
- **Game folders**
  - The app finds the game's data folder for **Steam, GOG and the Epic Games Store**.
  - It finds the mod wherever it is installed: **Mod Hub**, `mods` folder or staging area.
- **Mod**: a discreet logo button in the game's bottom bar, without text.

## Installation
**App**: download the file for your system below.

| System | File |
|---|---|
| Windows | `HQminiMap_1.0.0_x64-setup.exe` (or the `.msi`) |
| Windows, no install | `HQminiMap_1.0.0_x64-portable.zip` (unzip, then run `HQminiMap.exe`) |
| Linux | `.AppImage` (portable) or `.deb` |
| macOS (Apple Silicon and Intel) | `.dmg` |

**Mod**:
- subscribe to **HQminiMap** in the game's **Mod Hub**;
- or download `hqminimap-mod-1.0.0.zip` and copy its `hqminimap` folder into the `mods` folder of the game's data folder (Steam: `<Steam>/userdata/<SteamID>/3493540/local/mods/`; GOG and Epic: `%APPDATA%/Transport Fever 3/mods/`).

Then enable HQminiMap in your save.

## Good to know
- **Updating from 0.2.0**
  - Install this app version by hand once: automatic updates start with it.
  - Update the mod too, then **reload your save**.
  - **Export the map again** (in game: HQminiMap → *Export map*) and scan again: the export now carries water data used by the new basemap.
- The app needs **Microsoft WebView2** on Windows (already on Windows 11 and most Windows 10). The installers add it if needed; the portable zip includes `MicrosoftEdgeWebview2Setup.exe`.
- The installers are **not signed** yet: Windows SmartScreen (*More info* → *Run anyway*) and macOS Gatekeeper (right-click → *Open*) ask for a confirmation the first time.

Full guide: [README](https://github.com/Spit8/HQminiMap#readme).
